## Package publishing

**Package publishing** means uploading our own Node.js package to the **npm website**.

After publishing, other developers can install and use our package in their projects. We can share our **reusable code** with developers around the world.


## Real-time example:

#### Step 1: Create a project

```
mkdir my-calculator
cd my-calculator
npm init -y

```

#### Step 2 : Update package.json

```
    {
        "name": "my-calculator-sarav123",
        "version": "1.0.0",
        "description": "A simple calculator package",
        "type": "module",
        "main": "index.js"
    }
```

#### Step 3: Create JavaScript file - **index.js**

```
    export const add = (a, b) => {
        return a + b;
    };

    export const subtract = (a, b) => {
        return a - b;
    };
```

#### Step 4: Create README.md

```
# My Calculator

A simple calculator package.

## Installation

npm install my-calculator-sarav123

## Usage

import { add, subtract } from "my-calculator-sarav123";

console.log(add(10, 20));
console.log(subtract(20, 10));

```

#### Step 5: Check package contents

```
    npm pack --dry-run
```

- This command shows which files will be included in the published package. 
- Check that your package does not contain passwords, API keys, 
- **.env** files or other private information.

#### Step 6: Create an npm account

- Go to the npm website and **create an account**.

- Verify your email address before publishing.


### Step 7: Login to npm

- **npm login** connects your computer to your npm account. 
- **npm whoami** displays the username of the logged-in npm account.


Run this command in your project terminal:
```
    npm login
```

Then check your login:

```
    npm whoami
```

### Step 8: Publish the package

```
    npm publish
```
- This command uploads your package to the npm registry. 
- Once publishing succeeds, other developers can install your package.


npm may ask you to complete two-factor authentication (2FA), depending on your account and publishing settings.

```
npm publish --access public
```

### Step 9: Verify the package

Open the npm website and search for your package name.

```
https://www.npmjs.com/package/my-calculator-sarav123
```
