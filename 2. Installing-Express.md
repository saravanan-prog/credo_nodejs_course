# Steps to install Express.js

#### Step 1: Create a project folder
```
mkdir myproject
```

### Step 2: Go inside the project folder
```
cd myproject
```

### Step 3: Initialize the Node.js project
```
npm init -y
```

- npm init creates a **package.json file** in our project.

- The **package.json file stores project information** and installed package details.

- `-y` means accept the default ***settings automatically***.

### Step 4: Install Express.js
```
npm install express
```

### Express.js after installation

```
import express from 'express'

const app = express();

app.get('/', (req, res) => {
    res.send('Welcome to Express JS');
});

app.listen(3000, () => {
    console.log('Server is running');
});
```

### Run the application:
```
node server.js
```
