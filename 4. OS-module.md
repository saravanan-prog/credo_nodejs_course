## OS Module
- Node.js provides the built-in `OS module` 
- To get information about the `operating system`.


```
    import os from "os";
```

##### Methods

- `os.platform()` &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;-   get operating System 
- `os.arch()`&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;- &nbsp;get `cpu` Architecture
- `os.cpus().length`&nbsp;&nbsp;&nbsp;- get `cpu` Information
- `os.freemem()`&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;- get Total Memory
- `os.homedir()`&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; - get Home Directory
- `os.hostname()`&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;- get Hostname
```
    import os from "os";

    console.log("Platform:", os.platform());
    console.log("Architecture:", os.arch());
    console.log("CPU:", os.cpus().length);
    console.log("Free Memory:", os.freemem());
    console.log("Home Directory:", os.homedir());
```
