### 1. GET Method

 - **GET method** is used to get or retrieve data from the server.

- When the client wants to see some data, it sends a GET request to the server.

- The server receives the request and sends the requested data back to the client.

**GET Syntax**
```
GET /students HTTP/1.1

```
**Example**
```
const http = require('http');

const server = http.createServer((req, res) => {

    if (req.method === 'GET') {

        res.writeHead(200, {
            'Content-Type': 'application/json'
        });

        res.end(JSON.stringify({
            message: 'Getting student details',
            name: 'Arun',
            age: 22
        }));
    }

});

server.listen(3000, () => {
    console.log('Server running on port 3000');
});
```



### 2. POST Method

- **POST method** is used to **create new data** on the server.

- When the client wants to **add new information**, it sends a POST request.

- The server receives the information, processes it, and creates a new record.

```POST Syntax

    POST /students HTTP/1.1
    Content-Type: application/json

    {
        "name": "Arun",
        "age": 22
    }
```
### Example
```
const http = require('http');

const server = http.createServer((req, res) => {

    if (req.method === 'POST' && req.url === '/students') {

        let body = '';

        req.on('data', (chunk) => {
            body += chunk;
        });

        req.on('end', () => {

            const student = JSON.parse(body);

            console.log(student);

            res.writeHead(201, {
                'Content-Type': 'application/json'
            });

            res.end(JSON.stringify({
                message: 'Student created successfully',
                student: student
            }));

        });

    }

});

server.listen(3000, () => {
    console.log('Server running on port 3000');
});
```


### PUT Method

- **PUT method** is used to **update an existing resource** on the server.

- When the ***client wants to change existing information***, it sends a PUT request.

- PUT usually replaces the complete resource with the new data provided by the client.

**PUT Syntax**
```
PUT /students/1 HTTP/1.1
Content-Type: application/json

{
    "name": "Kumar",
    "age": 25
}
```
**Example**
```
const http = require('http');

let student = {
    id: 1,
    name: 'Arun',
    age: 22
};

const server = http.createServer((req, res) => {

    if (req.method === 'PUT' && req.url === '/students/1') {

        let body = '';

        req.on('data', (chunk) => {
            body += chunk;
        });

        req.on('end', () => {

            student = JSON.parse(body);

            res.writeHead(200, {
                'Content-Type': 'application/json'
            });

            res.end(JSON.stringify({
                message: 'Student updated successfully',
                student: student
            }));

        });

    }

});

server.listen(3000, () => {
    console.log('Server running on port 3000');
});
```



### DELETE Method

- **DELETE method** is used to **remove an existing resource** from the server.

- When the client wants to remove some data, it sends a DELETE request.

- The server identifies the resource and removes it if it exists.

**Syntax**
```
DELETE /students/1 HTTP/1.1
```
**Example**
```
const http = require('http');

let student = {
    id: 1,
    name: 'Arun',
    age: 22
};

const server = http.createServer((req, res) => {

    if (req.method === 'DELETE' && req.url === '/students/1') {

        student = null;

        res.writeHead(200, {
            'Content-Type': 'application/json'
        });

        res.end(JSON.stringify({
            message: 'Student deleted successfully'
        }));

    }

});

server.listen(3000, () => {
    console.log('Server running on port 3000');
});
```
