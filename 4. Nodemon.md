## Nodemon 

- **Nodemon** is a tool in Node.js that ***automatically restarts the serve***r whenever we make changes in our code.

- **Without Nodemon**, you must ***restart the server manually***.

- **With Nodemon**, the server ***restarts automatically*** when you save the file.

### Install Nodemon locally
```
npm install --save-dev nodemon
```

### Run the file using Nodemon

```
nodemon server.js
```

### Difference between Node and Nodemon
```
Node.js                                      Nodemon
---------------------------------------------------------------------------
Runs JavaScript files                       Runs JavaScript files

Does not automatically restart              Automatically restarts when
when code changes                           code changes

We restart the server manually              Restarts the server automatically

Used in development and production          Mainly used during development
```
