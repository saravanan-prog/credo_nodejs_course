## First Node.js Program

#### Step 1 : Create a folder  `node-learning`
#### Step 2 : Open the folder in VS Code.
#### Step 3 : Create a JavaScript file `app.js`
```
    node-learning
    │
    └── app.js

```
#### Step 4 : Write JavaScript: `Inside app.js`

#### Step 5 : Run the program : `node app.js`



```
                 app.js
                   │
                   │ JavaScript
                   ↓
                Node.js
                   │
                   ↓
               V8 Engine
                   │
                   ↓
              Execute Code
                   │
                   ↓
                Terminal
                   │
                   ↓
            Hello Node.js
            
```
