### HTTP

***HTTP*** is a communication rule that helps a client and a **server exchange data over the internet**.

### What is a Client and Server

**Client**: A client is a device or application that sends a request to a server.

***Examples***:

- Web browser (Chrome).
- Mobile application.
- Frontend application (React).

**Server**: A server is a computer or application that receives client requests and sends responses.

***Examples***:

- Node.js server.
- Java server.
- Python server.


###  Http works

### HTTP Request

**HTTP Request:** A request is a message sent from the client to the server to ask for some information or perform an operation.
An HTTP request contains important information.

- HTTP Method
- URL
- Headers
- Body

Syntax
```
HTTP/1.1 200 OK
Content-Type: application/json

{
  "message": "User fetched successfully",
  "name": "John"
}
```


### HTTP Response

**HTTP Response:** A response is a message sent from the server to the client after processing the request.

An HTTP response contains four important parts:

- HTTP Version
- Status Code
- Headers
- Body

**Syntax**

Syntax
```
HTTP/1.1 200 OK
Content-Type: application/json

{
  "message": "User fetched successfully",
  "name": "John"
}
```
