## Route Parameters
 - Route Parameters are dynamic values passed through a URL.
-  They help us get specific data based on an ID or another value from the URL.

Imagine we have a Student Management Application.
 ```
    http://localhost:8000/students/101
    http://localhost:8000/students/102
    http://localhost:8000/students/103
 ```

 ### Route Parameters Syntax

 ***syntax:***
 
   `req.params` – Contains route parameter values.
   
http://localhost:8000/students/101
 ```
    app.get("/students/:id", (req, res) => {
        console.log(req.params.id);
    });
 ```

 #### Multiple Route Parameters
 
 http://localhost:8000/students/101/Arun
 ```
 app.get("/students/:id/:name", (req, res) => {

    const id = req.params.id;
    const name = req.params.name;

    res.send(`ID: ${id}, Name: ${name}`);

});
 ```
#### Query Parameters
 http://localhost:8000/students?id=101
```
app.get("/students", (req, res) => {
    res.send(req.query.id);
});
```
