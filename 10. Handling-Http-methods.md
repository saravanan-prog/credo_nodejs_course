### Node.js – Handling HTTP Methods (GET, POST, PUT & DELETE) using Express.js


***GET Method – Read Data***

GET method is used to retrieve data from the server.
```
app.get("/students", (req, res) => {
    res.send("Get Student Details");
});
```

***POST Method – Create Data***

POST method is used to create new data on the server.
```
app.post("/students", (req, res) => {
    res.send("Student Added Successfully");
});
```

***PUT Method – Update Data***

PUT method is used to update an existing resource completely.

```
app.put("/students/:id", (req, res) => {
    res.send("Student Updated Successfully");
});
```

***DELETE Method – Delete Data***

DELETE method is used to remove an existing resource from the server.

```
app.delete("/students/:id", (req, res) => {
    res.send("Student Deleted Successfully");
});
```
