## Creating a Module
- In Every `JavaScript file` can be treated as a `module`.
- a large application into smaller modules is called `Modularity`





### How it works

```
          math.js
            │
            │ module.exports
            ↓
          app.js
            │
            │ require()
            ↓
         Uses add() and subtract()

```

#### Method 1: Common JS

`math.js`

```
    const add = (a, b) => {
        return a + b;
    };

    const subtract = (a, b) => {
        return a - b;
    };

    module.exports = {
        add,
        subtract
    };

```
Another file: `App.js`
```
    const math = require("./math");

    console.log(math.add(10, 20));
    console.log(math.subtract(20, 10));

```

#### Method 2: ES Modules => Modern JavaScript uses `import` and `export`.

`math.js`
```


export const add = (a, b) => {
    return a + b;
};

export const subtract = (a, b) => {
    return a - b;
};

```
`app.js`
```
import { add, subtract } from "./math.js";

console.log(add(10, 20));
console.log(subtract(20, 10));

```

#### Benefits

| Benefit         | Meaning                              |
| --------------- | ------------------------------------ |
| Reusability     | Use the same code in multiple places |
| Maintainability | Easier to modify code                |
| Organization    | Code is separated logically          |
| Testing         | Test individual modules              |
| Scalability     | Easier to build large applications   |
