## HTTP

- **HTTP** stands for **HyperText Transfer Protocol**.

- A client **sends a request** to the server.

- The server **receives the request** and **sends a response back to the client**.

- HTTP helps the **client and server communicate** with each other.


### HTTP Request

- An HTTP request is a message sent by a client to a server to ask for some data or perform an action.

- The client sends a request to the server.

- The request contains information such as the HTTP method, URL, and headers.


### HTTP Methods

HTTP methods tell the server what action the client wants to perform.

```
HTTP Methods

GET - Get data - Get user details

POST - Create data - Create a new user

PUT - Update data - Update user details

DELETE - Delete data - Delete a user

```


### HTTP Status Codes

HTTP status codes tell the client whether the request was successful or failed.

```
HTTP Status Codes

200 - OK - Request successful

201 - Created - New data created

400 - Bad Request - Invalid request

401 - Unauthorized - Authentication required

403 - Forbidden - Access not allowed

404 - Not Found - Resource not found

500 - Internal Server Error - Server problem

```
