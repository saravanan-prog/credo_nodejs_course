## JWT (JSON Web Token)

### What is JWT
- JWT stands for ***JSON Web Token***.
- JWT is used to ***securely transfer information*** between the `client` and `server`.
- In Express.js, we commonly use JWT for ***user authentication***.

 ***Step 1: Install package***
 ```
 npm install jsonwebtoken
 ```
 ***Step 2: Generate Token***


```
import jwt from "jsonwebtoken";

const token = const token = jwt.sign(
        { id: 101, email: "user@gmail.com" },     // db-record-payload
        process.env.JWT_SECRET,                   // secret-key

    );

console.log(token);
```

***Step 3: Verify Token (Custom Middleware)***

A ***request header*** contains additional information sent from the `client` to the `server`.

**Example headers**
```
    Authorization: Bearer your_jwt_token
    Content-Type: application/json
```
**Protection Route**
```
app.get("/profile", verifyToken, (req, res) => {
    res.json({
        message: "Welcome",
        user: req.user
    });
});
```


```
const verifyToken = (req, res, next) => {

    const token = req.headers.authorization?.split(" ")[1];

    if (!token) {
        return res.status(401).json({
            message: "Token missing"
        });
    }

    try {
        const decoded = jwt.verify(
            token,
            process.env.JWT_SECRET
        );

        req.user = decoded;
        next();

    } catch (error) {
        return res.status(401).json({
            message: "Invalid or expired token"
        });
    }
};
```
