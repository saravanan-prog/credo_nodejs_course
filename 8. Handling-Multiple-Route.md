## Handling Multiple Routes

- When an application has many routes, writing everything inside server.js becomes difficult'

- We can use Express Router to separate routes into different files.



```
Multiple-Routes/
    |
    |-- routes/
    |     |
    |     |-- studentRoutes.js
    |     |-- teacherRoutes.js
    |
    |-- server.js
```

***studentRoutes.js***
```
import express "express";

export const router = express.Router();

router.get("/", (req, res) => {
    res.send("Student Details");
});

router.post("/", (req, res) => {
    res.send("Add Student");
});
```
***teacherRoutes.js***
```
import express "express";

export const router = express.Router();

router.get("/", (req, res) => {
    res.send("Teacher Details");
});
```

***server.js***
```
const express = require("express");

const app = express();

// Import Routes
const studentRoutes = require("./routes/studentRoutes");
const teacherRoutes = require("./routes/teacherRoutes");

// Register Routes
app.use("/students", studentRoutes);
app.use("/teachers", teacherRoutes);

app.listen(8000, () => {
    console.log("Server running on port 8000");
});
```
