## Node.js – How to Update Local Packages

A local package is a package installed inside a particular Node.js project.

It is available to that project through its **node_modules folder**. 

### example
```
npm install express
```

### Package Update

**Updating a package** means changing its installed version to a `newer version`.

Example:

- **Current version:** Express 4
- **Newer version:**   Express 5

### Syntax to update local packages

```
    npm update (or) npm update package-name
```
Example:

```
    npm update express  
```
This updates Express according to the version range allowed in your package.json.
