## HTTP server using Express.js

-  imports the **Express.js module** into our project.

- **express()** creates an Express application.

- **app.listen()** starts the server and makes it listen for requests on the given port.

```
import express from 'express'

const app = express();

app.listen(8000, () => {
    console.log('Server is running');
});
```
###  Complete example of an HTTP server
- **'/'** Represents the home page URL path
- ***req*** - Contains request information
- ***res*** - Used to send a response
- ***res.send()*** - Sends a response to the client
- ***app.listen(3000)*** - Starts the server on port 3000
```
import express 'express';

// Create Express application
const app = express();

// Create a route
app.get('/', (req, res) => {
    res.send('Welcome to my Express Server!');
});

// Start the server
app.listen(3000, () => {
    console.log('Server is running on port 3000');
});

```

### Important Express.js methods
```
Method          Purpose
------------------------------------------------
app.listen()    Starts the server
app.get()       Handles GET requests
app.post()      Handles POST requests
app.put()       Handles PUT requests
app.delete()    Handles DELETE requests
res.send()      Sends a response
res.json()      Sends JSON data
````
