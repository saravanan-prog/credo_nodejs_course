## Async and Await

**Async and Await** are JavaScript keywords used to handle **asynchronous operations**.

- Sometimes, JavaScript needs to wait for a task, like getting data from a database or API.

- Async and Await help us handle these tasks easily without blocking the entire program.

- They make asynchronous code look simple and easy to read.


#### Syntax:


The **async** keyword is used before a function to make that function return a Promise.

```
async function functionName() {

    // Your code

}
```
 
The **await keyword** is used to wait for a Promise to finish and get its result.

```
async function functionName() {

    let result = await promise;

}

```
### Try and Catch with Async Await
Try and Catch are used to handle errors in asynchronous code.

```
async function functionName() {

    try {

        // Asynchronous code

    } catch (error) {

        // Handle error

    }

}
```
