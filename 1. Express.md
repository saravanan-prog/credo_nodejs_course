## 1. What is Express.js?

- **Express.js** is a **web framework for Node.j**s. It helps us create web applications and APIs easily.
- Express.js makes it easy to create a server using Node.js.
- It helps us handle client requests and send responses.
- It reduces the amount of code we need to write.
- It provides features like routing, middleware, and request handling.

**Remember**: Express.js is built on top of Node.js.

```
     CLIENT (Browser)
            |
            |
       HTTP Request
            |
            v
     EXPRESS.JS SERVER
            |
            |
      Process Request
            |
            v
       HTTP Response
            |
            |
            v
     CLIENT (Browser)

```

### 2. Why do we use Express.js?
- Express.js makes server creation and ***request handling easier***.

- In Node.js, we can create a server using the built-in HTTP module. But writing everything manually takes more code.



### Difference between Node.js and Express.js

| Node.js | Express.js |
| --- | --- |
| Node.js is a JavaScript runtime. | Express.js is a web framework. |
| It runs JavaScript outside the browser. | It helps build web servers and APIs. |
| It provides a built-in HTTP module. | It makes HTTP handling easier. |
| Express.js runs on Node.js. | Express.js depends on Node.js. |
