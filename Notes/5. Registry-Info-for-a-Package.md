## PACKAGE REGISTRY 

A **package registry** is an online place where developers can publish and share code packages.

In Node.js, **npm Registry** is the default online registry. 

We can download packages such as `Express`, `React`, and `Axios` from it.

**Practical example:**

- If you want to build a Node.js API
- you can download the Express package from the npm Registry.

```
You (Developer)
      |
      | Search for Express package
      v
npm Registry (Package Store)
      |
      | Shows package details
      v
Name: express
Version: 5.x
License: MIT

```

## Practical: 
Now show information about the Express package.
```
npm view express
```
To see only the latest published version, type:
```
npm view express version
```
