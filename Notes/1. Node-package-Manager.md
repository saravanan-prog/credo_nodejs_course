## NPM - Node Package Manager
- NPM stands for `Node Package Manager`.
- NPM is a `tool` that helps us install and manage `reusable` `JavaScript/Node.js` packages in our project. 
- NPM is the `default package manager` for `Node.js`.
- It helps us to:
```
    Install packages
    Remove packages
    Update packages
    Manage project dependencies
    Share/publish packages
    Download reusable code created by other developer

```

### NPM Package

- A package is `reusable code` that `someone has created and published`
- so that other developers can use it.

#### For example:

| Package    | Common usage                           |
| ---------- | -------------------------------------- |
| `express`  | Create web servers/APIs                |
| `mongoose` | Work with MongoDB                      |
| `axios`    | Make HTTP requests                     |
| `lodash`   | Utility functions                      |
| `nodemon`  | Automatically restart Node application |


##  Creating a Node.js Project

`Step 1` : Create a folder: `npm-demo`

`Step 2` : Open the folder in VS Code. and Open the terminal: `npm init -y`

&nbsp;&nbsp;&nbsp;&nbsp;  This command creates : `package.json`

### What is package.json

- `package.json` is a very important file in an NPM project.
- It contains information `about our project` and its `dependencies`.

```
    {
        "name": "npm-demo",
        "version": "1.0.0",
        "description": "",
        "main": "index.js",
        "scripts": {
            "test": "echo \"Error: no test specified\" && exit 1"
        }
    }
```
