## Promises

We use **Promises** to **handle asynchronous operations** in JavaScript.

Some tasks take more time to complete, such as reading a file or fetching data from an API.

Instead of waiting for one task to finish before writing other code, JavaScript can continue executing other tasks.

### Three states:
**Pending** - The operation is still running. We are **waiting** for the result.

**Fulfilled** - The operation is **completed** successfully. We got the expected result.

**Rejected** - The **operation failed**. Something went wrong.



### Syntax

- We create a Promise using the **new Promise()** constructor

- A Promise takes a callback function with two parameters: **resolve** and **reject**.

- resolve() is used when the operation is successful, and **reject()** is used when the **operation fails**.

```
let promise = new Promise((resolve, reject) => {

    // Write your code here

});
```

### Example

```
let promise = new Promise((resolve, reject) => {
    resolve("Success");
});

promise
    .then((result) => {
        console.log(result);
    })
    .catch((error) => {
        console.log(error);
    })
    .finally(() => {
        console.log("Task finished");
    });
```
` then()` - method is used to handle a successful Promise.

`catch()` - method is used to handle Promise errors.

`finally()` - method executes whether the Promise is successful or failed.
