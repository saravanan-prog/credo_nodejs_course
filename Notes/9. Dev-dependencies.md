## Node.js – Dev Dependencies

- **Dev Dependencies** are packages that we need only `during development`.

- These packages help developers `write`, `test`, `check`, and `build` the `application`.

- They are generally not needed when the application runs in production.


## Real-time example

Imagine you are building a house.
- Cement and bricks are needed in the final house.
- Construction tools are needed while building the house.

Syntax

```
    npm install package-name --save-dev
```

## Dependencies vs Dev Dependencies

```
Dependencies	                Dev Dependencies

Needed by application	        Needed during development
Used in production	            Usually not needed in production
npm install express	            npm install nodemon -D
Stored under dependencies	    Stored under devDependencies

```

## Important Dev Dependency packages

```
Package	        Purpose	                  Simple explanation

nodemon	        Auto restart	         Restarts Node.js server when code changes.
eslint	        Code checking	         Finds mistakes in JavaScript code.
prettier	    Code formatting	         Automatically formats our code.
jest	        Testing	                 Tests JavaScript functions.
dotenv-cli	Environment loading	         Loads .env values through command-line scripts.


```
