

### Node.js Architecture

- Node.js executes JavaScript on `one main thread` using the `V8 engine`.
- The `Event Loop` coordinates `asynchronous work`.
- libuv provides `important underlying mechanisms` for `asynchronous I/O`, 
- allowing Node.js to handle many concurrent I/O operations efficiently 
- without blocking the main JavaScript thread."

```
             Node.js
                │
    ┌───────────┼────────────┐
    ↓           ↓            ↓
 V8 Engine   Event Loop    libuv
    │           │            │
    ↓           ↓            ↓
Execute JS   Manage      Handle async
             tasks        operations
```

## 1. V8 JavaScript Engine

- V8 is the `JavaScript engine` that executes `JavaScript code`.

```
    JavaScript = Language
    V8         = Translator/Executor
    Node.js    = Complete Runtime Environment
```


## 2. Event loop

It helps Node.js manage` asynchronous operations`.

```
         CLIENT Browser / React
                   │
                   │ HTTP Request
                   ↓
            ┌──────────────┐
            │   Node.js    │
            │    Server    │
            └──────┬───────┘
                   │
                   ↓
              Event Loop
                   │
          ┌────────┴─────────┐
          ↓                  ↓
    Quick Task          Time-consuming Task
                              │
                              ↓
                         libuv / OS
                              │
                    ┌─────────┴─────────┐
                    ↓                   ↓
                 File I/O            Database
                    │                   │
                    └─────────┬─────────┘
                              ↓
                         Result Ready
                              │
                              ↓
                         Event Loop
                              │
                              ↓
                           Response
                              │
                              ↓
                            Client
```

- When Node.js needs to handle `certain asynchronous operations`, `libuv` and the underlying `operating-system facilities` help handle them.

