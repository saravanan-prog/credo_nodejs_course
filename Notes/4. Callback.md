## callback

A **callback** is a function that we pass as an argument to another function.

The **callback function is executed later** or when a particular task is completed.


### We use callbacks to:

- Execute one function after another function.
- Handle asynchronous operations.
- Handle API responses.
- Read files in Node.js.
- Handle events like button clicks.

### Example
```
function calculate(a, b, callback) {
    let result = a + b;

    callback(result);
}

function display(value) {
    console.log(value);
}

calculate(10, 20, display);

```


- Node.js uses callbacks for asynchronous operations like file reading.

- For example, we can read a file using the built-in fs module.

**Now create app.js**


```
const fs = require("fs");

fs.readFile("sample.txt", "utf8", (err, data) => {

    if (err) {
        console.log(err);
        return;
    }

    console.log(data);

});

console.log("File reading started");
```
### What is Error-First Callback?

**Error-First Callback** means the **first argument** of the callback function is used to **receive an error**.

The **second argument** is generally used to **receive the result** of the operation.


### Example:

```
const fs = require("fs");

fs.readFile("sample.txt", "utf8", (err, data) => {

    if (err) {
        console.log("Something went wrong");
        return;
    }

    console.log("File Content:", data);

});

```
