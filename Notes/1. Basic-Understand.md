## Node JS

- `Node JS` is a runtime environment that allows us to run `JavaScript outside the browser`.
- Normally, `JavaScript runs inside a browser` such as Chrome.
- With `Node.js`, JavaScript can `run directly` on a `computer/server`.

```
    JavaScript
        │
        ├── Browser → Frontend
        │
        └── Node.js → Backend
                       │
                       ├── APIs
                       ├── Files
                       ├── Database
                       └── Server

```

## Node.js Single-Threaded

- `JavaScript` execution in Node.js primarily happens on a `single main thread`,managed through the `Event Loop`.

-  `Event Loop`  Manages and schedules asynchronous tasks and their callbacks



```

                NODE.JS
                   │
                   ↓
          ONE MAIN JS THREAD
                   │
                   ↓
              Event Loop
                   │
        ┌──────────┼──────────┐
        ↓          ↓          ↓
     Request A  Request B  Request C
        │          │          │
        ↓          ↓          ↓
      File I/O   Database   Network
        │          │          │
        └──────────┼──────────┘
                   ↓
              Main thread is FREE
                   │
                   ↓
              Can handle more work



```
 `Non-blocking` The main thread `does not wait for a task to finish` and continues with other work.
