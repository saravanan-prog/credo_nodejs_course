## Installing a Node Package

- NPM has a `huge package registry` where developers publish packages.
```
    npm install express
```
- NPM `finds the express` package from the `NPM registry` and `downloads` it into our project.

### Example:

```

    npm-project
        │
        ├── node_modules           [ downloaded express ]
        │
        ├── package-lock.json      [ exact installation information ]
        │
        └── package.json           [ Updates package.json dependencies ]

```

### Using the Installed Package
Now create : `index.js`
```
import express from 'express'

const app = express();

app.get("/", (req, res) => {
  res.send("Hello from Express");
});

app.listen(3000, () => {
  console.log("Server running on port 3000");
});

```

Run project : `node index.js`

```
Server running on port 3000
```
Open Browser : `http://localhost:3000`
