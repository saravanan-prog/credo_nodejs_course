## Installing a Node Package

- NPM has a `huge package registry` where developers publish packages.
```
    npm install express
```
- NPM `finds the express` package from the `NPM registry` and `downloads` it into our project.

### Example:

```

    npm-project
        │
        ├── node_modules           [ downloaded express ]
        │
        ├── package-lock.json      [ exact installation information ]
        │
        └── package.json           [ Updates package.json dependencies ]

```
