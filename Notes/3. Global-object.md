## Global Object

 Node.js provides a `global object` that contains `values and functions` available throughout the application.

```
                 Node.js
                    │
                    ├── Global objects
                    │   ├── console
                    │   ├── process
                    │   ├── setTimeout()
                    │   └── Buffer
                    │
                    └── CommonJS module variables
                        ├── __filename
                        ├── __dirname
                        ├── module
                        └── exports
                        
```


Example

```
    console.log("Start");

    process.nextTick(() => {
        console.log("Next Tick");
    });

    console.log("End");

```
