## Path Module
- The `Path module` helps us work with `file` and `directory` paths.

```
    import path from "path";
```
- `path.extname(filepath)` - To Get File Extension
- `path.basename(filepath)`- To get File Name
- `path.dirname(filepath)` - To get Directory Name



### Example:
```
import path from "path";

const filepath = "/project/src/app.js"

console.log(path.basename(filepath));     // app.js
console.log(path.extname(filepath));      // .js
console.log(path.dirname(filepath));      // /project/src

```
### Join path

```
path.join("project", "src", "app.js")  - Join Paths 
```
Output::
```
project/src/app.js

```
