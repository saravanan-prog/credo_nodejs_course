## 1. Introduction to Node.js Modules

#### What is a Module?

- A `module` is a `separate JavaScript file` that contains related code.
- Instead of writing the entire application in one file, 
- we divide the application into `smaller files` called `modules`.


#### Modules help us:

- Organize code
- Reuse code
- Maintain code easily
- Avoid writing duplicate code
- Separate different responsibilities
- Make large applications easier to manage

#### Example 
Without modules:

```
      app.js
        ├── user code
        ├── product code
        ├── payment code
        ├── database code
        └── authentication code



```
With modules:
```
      project/
        │
        ├── app.js
        ├── user.js
        ├── product.js
        ├── payment.js
        ├── database.js
        └── auth.js
```
