### Synchronous


- **Synchronous** means executing the **code one by one**, step by step. 
- The next task will wait until the current task is completed.

### Explanation:

- First, Node.js executes the first task.

- After completing the first task, it moves to the second task.

- It does not move to the next task until the current task finishes.

- This is also called Blocking Code.

### Example:
```
import fs from 'fs'

console.log("Start");

const data = fs.readFileSync("data.txt", "utf8");

console.log(data);

console.log("End");

```



###  Asynchronous

- **Asynchronous** means executing a **task without waiting for that task to finish**. 
- Node.js can continue doing other work while waiting for the task to complete.

Explanation:

- Node.js starts the first task.

- If the task takes time, Node.js can continue with other tasks.

- When the first task is completed, its result is handled later.

- This is also called Non-Blocking Code.

```
const fs = require("fs");

console.log("Start");

fs.readFile("data.txt", "utf8", (err, data) => {
    if (err) {
        console.log(err);
        return;
    }

    console.log(data);
});

console.log("End");
```
