## File System
- The File System (fs) module allows Node.js to work with `files` and `directories`.
- We can:

```
    Create files
    Read files
    Write files
    Update files
    Delete files
    Create directories
```

| Method             | Purpose          |
| ------------------ | ---------------- |
| `readFileSync()`   | Read file        |
| `writeFileSync()`  | Write file       |
| `appendFileSync()` | Add content      |
| `mkdirSync()`      | Create directory |
| `unlinkSync()`     | Delete file      |


#### Reading File

```
import fs from 'fs'

const data = fs.readFileSync("message.txt", "utf8");
console.log(data);

```

#### Writing a File

```
import fs from 'fs'

fs.writeFileSync("message.txt", "Hello Node.js");

```

#### Appending to a File
```
import fs from 'fs'

fs.appendFileSync("message.txt", "\nWelcome Students");

```
#### Deleting a File

```
import fs from 'fs'

fs.unlinkSync("message.txt");
```

#### Creating a Directory
```
import fs from 'fs'
fs.mkdirSync("demo");
```
