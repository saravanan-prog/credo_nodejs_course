### Callback Hell

- **Callback Hell** happens when we write many **callbacks inside other callbacks**.

- The code becomes **difficult to read**, understand, and maintain.

- It is also called the Pyramid of Doom because the code looks like a pyramid.

```
function first(callback) {

    setTimeout(() => {

        console.log("First");

        callback(() => {

            setTimeout(() => {

                console.log("Second");

                callback(() => {

                    console.log("Third");

                });

            }, 1000);

        });

    }, 1000);
}
```
