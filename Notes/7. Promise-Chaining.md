## Promise Chaining Syntax

We use **multiple .then() methods** one after another to create Promise Chaining.

### Syntax
```
promise
    .then((result) => {

        // First task

        return result;

    })
    .then((result) => {

        // Second task

        return result;

    })
    .then((result) => {

        // Third task

        return result;

    })
    .catch((error) => {

        // Handle error

    });
```
- The `first .then()` receives the result from the Promise.
- It performs an operation and returns a value or another Promise.
- The next .then() receives that returned value.
- The .catch() handles errors in the chain.

### Example

```
let promise = new Promise((resolve, reject) => {

    resolve(10);

});

promise
    .then((result) => {

        console.log(result);

        return result * 2;

    })
    .then((result) => {

        console.log(result);

        return result * 2;

    })
    .then((result) => {

        console.log(result);

    });
```
