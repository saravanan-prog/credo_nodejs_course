## Asynchronous Programming

- **Asynchronous programming** means Node.js `does not need to wait for one task to finish` before starting another task.

- It can do other work while waiting for a task to finish.

## Why do we need it in Node.js?

- In Node.js, some tasks take more time.
- If Node.js waits for every task, the application becomes slow.
- Asynchronous programming helps Node.js do other work while waiting.

Examples:

- Reading a file.
- Writing a file.
- Connecting to a database.
- Getting data from an API.
- Sending emails.


## Now create app.js.

```
import fs from 'fs';

console.log("Program Started");

fs.readFile("student.txt", "utf8", (err, data) => {

    if (err) {
        console.log(err);
        return;
    }

    console.log(data);

});

console.log("Program Ended");

```
