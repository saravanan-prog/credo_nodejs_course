## HTTP Module
- The `HTTP module` allows Node.js to create an `HTTP server`.
```
 import http from 'http'
```
#### HTTP Request Flow
```

          Browser
            │
            │ HTTP Request
            ↓
        Node.js HTTP Server
            │
            │ req
            ↓
        Request Handler
            │
            │ res
            ↓
        HTTP Response
            │
            ↓
         Browser
```

#### Create a Server
```
    import http from 'http'

    const server = http.createServer((req, res) => {
        res.write("Hello Node.js");
        res.end();
    });

    server.listen(3000);
```
- `http.createServer()`  - Creates an HTTP server.
- `req` - It contains information about the client's request.
```
req.url
req.method
```
res - `res` means Response.

```
res.write("Hello");
res.end();
```
 `server.listen()`

```
    server.listen(3000);

```
