### 1. NPM Packages and Source Control


Source control is a system used to `track` and `manage changes` in our project files.

```
     Developer
        ↓
     Changes code
        ↓
       Git
        ↓
      Commit
        ↓
     GitHub / GitLab / Bitbucket

```
### 2. Should We Commit

```
    MyProject
    │
    ├── src/
    ├── package.json        ✅ Commit
    ├── package-lock.json   ✅ Commit
    ├── index.js            ✅ Commit
    └── node_modules/       ❌ Don't commit

```

Should We Commit node_modules - `❌ No`

`Step 1` : Create a file called :  `.gitignore`

`Step 2` : `.gitignore` inside add `node_modules/`


### 3. Then How Does `Another Developer` Get the Packages?

 Suppose `Developer A` pushes the `project` to `GitHub`.

```
    package.json
    package-lock.json
    src/
    .gitignore

```
- Developer B `clones the project`.
- There is no `node_modules`

```
    npm install
```
