## Process Form Data 
In Node.js, we commonly use the Express.js framework to process form data easily.


### For JSON data
```
app.use(express.json());
```
express.json() parses incoming JSON request bodies, 

### For HTML form data

```
app.use(express.urlencoded({ extended: true }));
```

- It is middleware used to read form data submitted using URL-encoded format.

- When an HTML form sends data using method="POST", this middleware helps Express read the submitted form values through req.body.

***Example**
```
<form action="http://localhost:3000/register" method="POST">

  <input type="text" name="username">

  <input type="email" name="email">

  <button type="submit">Submit</button>

</form>
```


Use both in your application. There is no problem using both together. Express will process the request according to its content type.




```
import express from 'express'
const app = express();

app.use(express.urlencoded({ extended: true }));
app.use(express.json());

app.post('/register', (req, res) => {

    const username = req.body.username;
    const email = req.body.email;

    res.send(`Welcome ${username}! Your email is ${email}`);

});

app.listen(3000, () => {
    console.log('Server running on port 3000');
});
```
