## Sending a Response

- **Sending a response** means sending data from the server **back to the client** after receiving a request.

- The **res** object is used to **send a response** from the server to the client.


### Different Ways to Send a Response

**1. res.send()**

**res.send()** is used to **send a response** to the client

```
const express = require('express');

const app = express();

app.get('/', (req, res) => {
    res.send("Welcome to Node.js");
});

app.listen(3000);
```

**2. res.json()**

**res.json()** is used to **send JSON data** from the server to the client.
```
app.get('/user', (req, res) => {

    res.json({
        name: "Arun",
        age: 22,
        city: "Chennai"
    });

});
```

**3. res.status()**

**res.status()** is used to send an HTTP status code to the client.
```
app.get('/home', (req, res) => {

    res.status(200).send("Success");

});
```

4. **res.sendFile()**

**res.sendFile()** is used to send a file from the server to the client.

```
const path = require('path');

app.get('/page', (req, res) => {

    res.sendFile(
        path.join(__dirname, 'index.html')
    );

});

```

### Complete Example

```
const express = require('express');

const app = express();

// Sending text response
app.get('/', (req, res) => {
    res.send("Welcome to my website");
});

// Sending JSON response
app.get('/user', (req, res) => {
    res.json({
        name: "Arun",
        age: 22
    });
});

// Sending status response
app.get('/success', (req, res) => {
    res.status(200).send("Request Successful");
});

// Starting server
app.listen(3000, () => {
    console.log("Server running on port 3000");
});
```
