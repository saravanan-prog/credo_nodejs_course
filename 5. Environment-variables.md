## Environment Variables

***Environment Variables*** are variables used to store **important information** about our application **outside the source code**.

They help us store information like:

- Database username
- Database password
- API keys
- Port number
- Application settings

### Install dotenv package
```
npm install dotenv
```
***dotenv*** is an npm package used to load values from the **.env file** into process.env.

It helps our Node.js application read **Environment Variables** stored in the .env file.

### .env file

A `.env` file is a ***simple text file*** used to store Environment Variables.
We normally create this file in the root folder of our Node.js project.

```
PORT=3000
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=admin123
```

### Write code inside server.js

```
import dotenv 'dotenv'
dotenv.config()

const port = process.env.PORT;
const appName = process.env.APP_NAME;

console.log(port);
console.log(appName);

```
