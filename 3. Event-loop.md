## Event Loop in Node.js

**Node.js** uses the Event Loop to **handle asynchronous operations**.

The **Event Loop** is a **mechanism in Node.js** that helps JavaScript handle **asynchronous operations** without blocking the main thread.

#### Main components

**Call Stack** : The Call Stack is a place where JavaScript keeps track of functions that are currently executing.

```
function first() {
    console.log("First function");
}

function second() {
    console.log("Second function");
}

first();
second();

```

**Node.js APIs (libuv and operating system)** -


Node.js uses its runtime facilities, including `libuv` and operating-system support, to handle asynchronous operations.

```
const fs = require("fs");

fs.readFile("test.txt", "utf8", (err, data) => {
    console.log(data);
});

console.log("File reading started");

```

**Callback Queue** - The Callback Queue `holds callbacks` that are ready to execute.

**Event Loop** - The Event Loop coordinates the `execution of callbacks` and other tasks.

**Microtask Queue** - The Microtask Queue contains `Promise` `callbacks` and other microtasks waiting to execute.
